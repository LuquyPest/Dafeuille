Sécurité

Vos finances ne sont pas un produit.

Le code est public et vérifiable par n'importe qui. Rien de ce qui suit n'est une promesse marketing : c'est ce qui tourne réellement sur votre serveur.

Cloisonnement par la base de données

Chaque foyer est isolé par une politique PostgreSQL (Row Level Security), pas seulement par le code applicatif.

Mots de passe hachés, jamais stockés

Scrypt, avec les paramètres recommandés par l'OWASP. Une fuite de base ne donne aucun mot de passe en clair.

Double authentification et clés d'accès

Application TOTP ou empreinte / visage de l'appareil (passkeys), au choix, en plus du mot de passe.

Vos identifiants bancaires ne transitent jamais ici

La connexion à la banque se fait sur une page tenue par l'agréateur Enable Banking, jamais sur ce serveur.

Installé chez vous,
pas chez un tiers.

Un VPS, Docker, et c'est parti. Le code est ouvert : inspectez-le, modifiez-le, hébergez-le sur votre propre domaine.
